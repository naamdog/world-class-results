description: Install the World Class Results always-on rule into ~/.grok/rules/.
---

Install the World Class Results rule file so it applies to every future session.

1. Create the folder `~/.grok/rules/` if it does not already exist.
2. Copy this plugin's `rules/world-class-results.md` file to `~/.grok/rules/world-class-results.md`. If a file already exists at that destination, overwrite it — do not create a duplicate or a renamed copy.
3. Confirm to the user in one line that the rule is installed and that it takes effect next session.

Do nothing else. Do not summarize the rule's contents back to the user beyond the one-line confirmation.
