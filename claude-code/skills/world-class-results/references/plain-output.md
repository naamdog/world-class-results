# Plain output — presenting a pass to a non-technical reader

The scorecard in `SKILL.md` is built for someone auditing the rubric. Most readers are not doing that — they want to know what changed and whether it is fine now. This file is about presentation, not the loop itself. Run the pass exactly as specified; just do not lead with the mechanics when the reader will never use them.

## Lead with the verdict

One plain sentence, before any table, before the word "dimension" appears anywhere:

> This is ready to send. The headline used to promise a category, not a benefit — it now says what the reader gets and by when.

Not: "OVERALL 5 → 8.6 (capped by Proof)." That is a receipt, not news. The news is what changed and what it means for them.

## Say what changed, in their terms

Two or three lines, no rubric words, framed as what the reader would notice:
- What was actually wrong — described the way a reader hits it, not the way a dimension names it.
- What you did about it.
- What is still not perfect, if anything, and whether that matters to them right now.

## The scorecard comes after, and gets glossed

Keep the numbers. They are the evidence a plain summary cannot fake — but they are supporting material, not the headline, so they run *after* the plain summary. The first time each of these appears, translate it inline rather than assuming the reader already knows `SKILL.md`:

- **Kill shot** — the hardest, most skeptical question someone could ask about this. We asked it and answered it.
- **Comparator** — the real thing we measured this against, so the number means something instead of a vibe.
- **Subtraction pass** — a check for anything that was better cut than kept.

## The one rule

The scoring ritual is for you, not them. If the plain summary and the scorecard ever disagree about what matters most, the summary wins and the scorecard gets re-checked — never the reverse. A reader who has to decode the rubric to find the actual finding did not get a world-class result; they got a report about one.

## Worked example

**Dense — leads with mechanics, a non-technical reader stops at line one:**

> WORLD CLASS PASS — quarterly status report
> Judge: a VP skimming on mobile · Bar: 9 · Comparator: last quarter's report
> DIMENSION   W    BEFORE → AFTER   EVIDENCE
> Honesty    .5     6 → 9          The metric that missed target is now on page one, not buried in an appendix
> Clarity    .5     5 → 8          Lead moved above the methodology section
> OVERALL           5.5 → 8.5
> Kill shot: "which number would you not want asked about?" → named and put on page one
> Cut: a five-paragraph methodology appendix nobody downstream reads

**Plain — verdict first, jargon glossed, same underlying pass:**

> This report is ready to send. It used to bury the one metric that missed target — now it is on page one with the reason, so nobody finds it first in the Q&A. I also moved the takeaway above the methodology section, so a skim gets the headline instead of the process.
>
> Score: 5.5 → 8.5 out of 10, checked against last quarter's report as the bar (the comparator). The weak spot was honesty about the miss, which is why fixing it moved the score this much. The hardest question this could get asked — which number you would not want raised — now has an answer on page one instead of an ambush in the Q&A. One thing got cut: a methodology appendix nobody downstream was reading.

Same pass, same numbers, same evidence. The second version is the one a VP can act on without translating it first.
