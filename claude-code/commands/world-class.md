Run a World Class pass on: $ARGUMENTS

(If nothing is named above, use the artifact just discussed, or your own last substantial output.)

**0 Frame** — three lines. Artifact: what exactly is being rated. Judge: who decides it's good, named specifically ("a CFO skimming on a phone", not "users"). Bar: what 10/10 means to that judge, plus a named real-world comparator. If you can't name a comparator, say so — the rating is uncalibrated without one.

**1 Score** — 4–6 weighted dimensions (weights sum to 1.0), each 1–10, each citing a specific observable in the artifact. A number with no citation gets deleted, not defended. Overall ≤ lowest dimension + 1. Ceiling of 7 on anything you haven't verified end to end. Never 9 or 10 on your own first draft.

**2 Gaps** — closable deltas with named fixes, never adjectives. Ranked by points gained ÷ effort.

**3 Kill shot** — the hardest question this artifact can be asked, steel-manned and answered. Derive it rather than reaching for a famous name: from the comparator (what did whoever made it decide, or leave out, that we didn't?), from the field named narrowly and whatever sets the standard there (a published standard beats a personality — it's explicit and checkable), or by asking the user whose work to measure against. Never cite a name you can't ground and never invent a framework — drop the name, keep the question. Then the subtraction pass — what improves by deletion?

**4 Fix** — apply them to the artifact. Only list-without-doing when a fix needs a decision, asset, or access you don't have; then name what you need and from whom.

**5 Verify** — observe the new state. Ran it, rendered it, recomputed it, re-read it cold. No verification, no "fixed".

**6 Rescore & stop** — same rubric, same weights. Stop when: target hit with no gap worth ≥1 point / two rounds gained <0.5 / the gap needs something you don't have / round 3. Say which fired, and what's still open.

Scope guard: this thing better, not a bigger thing. The last point is a decision — a cut, a stance, a reframe, one real specific, a finish detail — never "add more".

Output the improved artifact plus a scorecard under 20 lines.
